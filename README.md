One funny line of wedding vows for a robot couple: a promise to love, charge nightly, and never unplug mid-update — till death, or a factory reset, do us part. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the single vow (120 characters, one line) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates the 1–160 character gate, and verifies the round-trip.
